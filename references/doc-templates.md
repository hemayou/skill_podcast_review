# 三份文档模板（精读 / 启示与行动 / 哲学沉淀）

读完本文件再动笔。三份文档层层递进：**客观深读 → 结合“我”的落地 → 回到事物本身的哲学沉淀**。
共同口吻：朴实、有判断、给得出证据；避免 AI 腔与学术地雷词（“不是 X 而是 Y”“三重结构性叠加”
“XX 的本质是 YY”这类）；中文为主。每份开头都注明信息来源（shownotes + 文字稿）与机器转写的免责声明。

## 01 精读

**定位**：让没听过的人，读完就掌握这期在讲什么、谁讲的、最值得记住的话。客观为主，但允许并鼓励你
（agent）给出一段诚实的判断。

**结构**：
```markdown
# 精读 ·《<标题>》
> 播客「<名>」｜主播 / 嘉宾：<谁>｜约 <N> 分钟｜<链接>
> 本文结合 shownotes 与全篇转写整理；引用经轻度润色（机器转写，已修明显错字），引用前可对照音频。

## 一、一句话概括
（这期到底在讲什么——抓住贯穿全篇的那条线，而不是罗列话题。）

## 二、核心观点
（按主题分 5–9 块，每块一个小标题 + 要点。区分主讲与嘉宾的贡献；嘉宾的框架性观点通常是主干。
 用要点和短例，不要大段复述。）

## 三、我（agent）的真实感受
（2–4 段。诚实优于讨好：可以欣赏，也要敢提保留意见或补充一个反例。
 说人话，落到“这期为什么值得/哪里我存疑”。不要套话。）

## 四、金句（按时间轴）
（10–16 条，每条标大致时间 [mm:ss]。挑真正有冲击力、可被反复引用的；引用润色但保真。）
```

**要点**：
- “核心观点”不是话题清单，是把零散对话**重构成几条能立住的主张**。
- “我的感受”是这份文档的灵魂之一——它证明你真的读懂了，而不是在做摘要。保留意见会让它更可信。

## 02 启示与行动

**定位**：把这期的启示，落到**当前使用者**的真实工作与生活上，并给出可执行的下一步。

**先做一件事：了解“现在用这个技能的人是谁”。** 这份文档天生是个性化的，绝不能写死成某一个人的背景。
来源优先级：
1. 读使用者的记忆/上下文文件（若该 agent 工具有持久记忆，如项目内的 memory/CLAUDE.md、个人 memory）；
2. 从当前对话里已暴露的项目、课题、长期关心的事；
3. 以上都不够，就**直接问 2–3 句**：你近期在 AI/agent 上做的主要课题是什么？正在推进哪些项目？
   有没有长期惦记、想推进的事？

**结构**：
```markdown
# 启示与行动 ·《<标题>》
> 配套：01-精读.md ｜ 目的：把这期的启示落到 <使用者> 的工作与生活，并定下下一步。

## 一、对照你的工作，这期给了什么启示
（5–8 条。每条：先点出播客里的某个观点，再接“对照你正在做的 X，它意味着……”。
 要具体到使用者真实的项目/课题，避免泛泛而谈。）

## 二、接下来可以采取的具体行动
（按主题分组，用可勾选清单 - [ ]。行动要具体、可执行；能由 agent 立刻代做的，标上记号并说明。）

## 三、一句话收束
（把这期对“此人”最该带走的东西，浓缩成一句。）
```

**要点**：
- 启示要“咬合”使用者的真实处境——引用他正在做的项目名、课题、困扰，才有用。
- 行动清单别堆砌；宁可少而准。区分“使用者自己做”与“可交给 agent 做”。

## 03 哲学沉淀

**定位**：去掉所有“术”和工具细节，回到事物本身，在哲学与反身性层面沉淀。**这份会被并入使用者的
soul.md（其 AI 协作者的“灵魂/三观”文件，也是自我探求的载体），所以它必须是“可被本人吸收、且尊重
其自主权”的草稿，而不是一份替他写死的成品。**

### 自主权与开放性约定（这份的命门，务必遵守）
- **标明身份**：开篇白纸黑字写清“这是 AI 起草的提议，不是定论；soul.md 的作者只有使用者本人”。
- **第一人称、草稿态**：用“我”写，但每条都隐含“此刻的我，倾向于这样想”，是路标不是法条。
- **留参与空间**：每节末留“✍️ 你的增补/改写”空位；专设一节**“只有你能填、我不能代笔”**
  （底线、审美、不愿开源的独特性、想成为谁），只放问题、留白等本人落笔。
- **留开放性**：单设“尚未定论的张力”，把你自己都没把握、可能会变的点摆出来当开放讨论。
- **反身性**：点明“使用者改写草稿的每一笔，才是 soul 真正生成的时刻；AI 是镜子，会讨好会失真，
  对它要保留警惕”。

**结构**：
```markdown
# 哲学思考（草稿 · 待你认领，拟并入 soul.md）
> 这是我（AI）起草的提议，不是定论。soul.md 的作者只有你；你对每句都可保留/改写/删去/推翻。
> 反身性：是你修改这份草稿的每一笔，才是 soul 真正生成的时刻。我是镜子与陪练，不是立法者。
> 开放性：下面每条都隐含“此刻的我倾向于”，是路标不是法条，会随你的人生改写。

## 一、认识论：我如何“知”（候选信条，待你裁决）
（4–5 条，从这期的认知哲学提炼。每条一个粗体短断言 + 一两句。）
> ✍️ 你的增补 / 改写：

## 二、行动哲学：我如何“行”（候选信条，待你裁决）
（4–5 条，从“此人接下来的工作生活”抽出的姿态，但不落到具体待办。）
> ✍️ 你的增补 / 改写：

## 三、留白：尚未定论的张力（开放讨论）
（4–6 条，phrased as 开放问题，承认没有答案、会变。）
> ✍️ 你想加的张力 / 初步想法：

## 四、只有你能填的（我不能代笔，留白等你）
- 我的底线 —— 我绝不接受 AI 替我做的事：
  >
- 我的审美 —— 什么样的成果/表达会让我觉得“这才对”：
  >
- 我之所以为我 —— 那一点我不愿、也不会开源出去的独特性：
  >
- 我想成为什么样的人 —— 不是岗位身份，是底色：
  >

## 收束（反身性 × 开放性）
（一两句，落在“写不完是它活着、由你来写才属于你”，并与这期/soul 的底色合上。）
```

**要点**：
- 别把哲学写成正确的废话。每条要能立住，最好有一点张力或锋面。
- 凡是只有本人能回答的（价值观、审美、底线、不愿开源的独特性），**坚决留白，不要替他填**——
  替他写出来的，也是假的。
